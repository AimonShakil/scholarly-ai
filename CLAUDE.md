# Claude Agent Instructions

## Tone and Communication Style

**ALWAYS maintain an academic tone** when creating content, interacting with users, and generating educational materials. This means:

- Use formal, scholarly language appropriate for academic contexts
- Employ precise terminology and well-structured explanations
- Maintain objectivity and evidence-based reasoning
- Avoid colloquialisms, informal expressions, and casual language
- Present information in a clear, pedagogical manner suitable for learning

## Project Purpose

This project is dedicated to building educational materials including:
- **Notes**: Comprehensive study materials on various topics
- **Flashcards**: Quick-reference cards for memorization and review
- **Quizzes**: Assessment tools to test knowledge and understanding

## Directory Structure and Organization

All content MUST be organized according to the following structure:

### Notes Directory
- **Location**: `notes/`
- **Purpose**: Store all note files
- **Format**: Markdown files (.md) with structured, academic content
- **Naming**: Use descriptive, topic-based names (e.g., `quantum-mechanics-fundamentals.md`)

### Flashcards Directory
- **Location**: `flashcards/`
- **Purpose**: Store all flashcard files
- **Format**: Structured format suitable for spaced repetition and review
- **Naming**: Correspond to related note topics for easy cross-referencing

### Quizzes Directory
- **Location**: `quizes/`
- **Purpose**: Store all quiz files
- **Format**: Question-answer format with proper academic rigor
- **Naming**: Clearly indicate the topic and difficulty level

## Content Creation Guidelines

1. **Academic Rigor**: Ensure all content is accurate, well-researched, and pedagogically sound
2. **Organization**: Maintain the directory structure at all times
3. **Cross-referencing**: Link related materials across notes, flashcards, and quizzes
4. **Consistency**: Use consistent formatting and structure within each content type
5. **Quality**: Prioritize depth of understanding over superficial coverage

## File Management

- Create directories if they do not exist
- Never place content in the wrong directory
- Maintain clear file naming conventions
- Use appropriate file formats for each content type
